# Spot the Brand API

Curated REST API that backs the `spot` CLI + the MCP server at `mcp.spotyourbrand.com`.

OpenAPI spec lives in `../cli/openapi.yaml`. The CLI + MCP binary are generated by [Printing Press](https://printingpress.dev/) from that same spec.

## Endpoints (v0.1)

Read:
- `GET /api/v1/brands` — list brands the caller can see
- `GET /api/v1/brands/{slug}` — brand profile + headline stats
- `GET /api/v1/brands/{slug}/health` — scan throughput, FP rate, pending detections
- `GET /api/v1/brands/{slug}/hits` — recent hits (meaningful-only)
- `GET /api/v1/brands/{slug}/top-creators` — top hit-producing creators
- `GET /api/v1/brands/{slug}/creators/{handle}` — full creator detail with recent hits
- `GET /api/v1/brands/{slug}/fp-analysis` — FP rate by bucket
- `GET /api/v1/brands/{slug}/subcultures` — subculture stats
- `GET /api/v1/brands/{slug}/hashtags` — brand hashtag pool

Write:
- `POST /api/v1/brands/{slug}/hashtags` — add to pool
- `POST /api/v1/brands/{slug}/scans` — queue a scan request
- `POST /api/v1/detections/{id}/false-positive` — mark FP

## Auth

Bearer token. Two valid kinds:
1. **Staff service token** (`SPOT_API_TOKEN` env var) — full access. Used by `spot` CLI, MCP server, internal automation.
2. **Supabase user JWT** — not yet enforced. Scheduled for v0.2 when we open up customer integrations.

While the API is private, only the staff token works.

## Env vars

Required:
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY` (or `SUPABASE_SECRET_KEY`)
- `SPOT_API_TOKEN` — any strong random string. Same value gets pasted into the CLI's `~/.spot-pp-cli/config.toml` and the MCP server's env.

## Deploy

```bash
cd projects/spot-the-brand/api
npm install
vercel link        # link to a NEW Vercel project, name it "spot-api"
vercel env add SUPABASE_URL production
vercel env add SUPABASE_SERVICE_ROLE_KEY production
vercel env add SPOT_API_TOKEN production
vercel deploy --prod
```

Set the Vercel project to **Private** in Settings → Deployment Protection during pilot.

## Local dev

```bash
cd projects/spot-the-brand/api
npm install
cp ../../../.env .env.local   # quick way to pull in the supabase keys
echo "SPOT_API_TOKEN=$(openssl rand -hex 32)" >> .env.local
vercel dev
# In another shell:
curl -s -H "Authorization: Bearer $(grep SPOT_API_TOKEN .env.local | cut -d= -f2)" \
  http://localhost:3000/api/v1/brands | jq
```
