## 12. Brand discipline tests for every post

Before scheduling, ask:
1. Does this post sound like Spot the Brand, or like a customer?
2. If we removed the customer reference, does it still work?
3. Is there a single concrete number or example?
4. Does it have a clear next action?

If 1 or 2 fails → rewrite. If 3 or 4 fails → cut it shorter and resubmit.
